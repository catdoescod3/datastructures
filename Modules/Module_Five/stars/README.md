- Compile the program by doing `g++ main.cpp -std=c++23 -o stars`
- Run using ./stars <star_depth> [star_lines]
- Providing <star_depth> will display lines of stars with the maximum
  line being <star_depth> long
- Providing <star_lines> will display <star_lines> lines of stars,
  where the maximum star length is <star_lines> / 2.
